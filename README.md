# INGITO 

**Ингито** — мессенджер для Android, в котором регистрация не требует телефона или почты. Вход — только ник и пароль, а вместо SMS-кодов — ключ восстановления.

## Скачать (Android)

1. Скачайте APK: **[Ingito.apk](https://github.com/Danil7G/INGITO/releases/latest/download/Ingito.apk)**
2. Откройте файл — Android спросит разрешение на установку
3. Готово

## Честно о скорости

INGITO живёт на самом скромном сервере — и я не считаю нужным это скрывать. Канал узкий: отправка и загрузка фото и файлов могут идти медленно (десятки килобайт в секунду), а в час пик возможны паузы.

Это осознанный старт: приложение уже готово и работает, а сервер растёт вместе с аудиторией. Каждая поддержка через кнопку «Поддержать разработчика ♥» в приложении идёт именно на инфраструктуру.

Спасибо за понимание — скорость будет расти вместе с INGITO. 🙏
